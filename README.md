# Developer Portfolio

A single-page portfolio built with Next.js (App Router) and plain JavaScript. No TypeScript.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Make it yours

All content lives in `data/portfolio.js`: your name, photo, bio, projects, skills and contact links. Edit that one file and every section updates.

Colors, fonts and spacing are CSS variables at the top of `app/globals.css`.

## Deploy

Push the folder to GitHub, then import it at vercel.com. No extra settings are needed.

```bash
npm run build
npm start
```
